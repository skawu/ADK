# Build and Test Matrix

> Record commands that have been verified in this repository. A command copied from documentation but not executed must be marked unverified.

| Target / configuration | Prerequisites | Configure/build command | Test command | Result / evidence | Notes |
|---|---|---|---|---|---|
| Host development | UNKNOWN | UNKNOWN | UNKNOWN | NOT RUN | Fill from project evidence |
| Cross-compile target | UNKNOWN | UNKNOWN | UNKNOWN | NOT RUN | Fill only if applicable |
| Simulator / emulator | UNKNOWN | UNKNOWN | UNKNOWN | NOT RUN | Fill only if applicable |
| Bench / hardware | UNKNOWN | UNKNOWN | UNKNOWN | NOT RUN | Document safe procedure |

## Result definitions

- PASS: command executed and acceptance criteria met.
- FAIL: command executed and acceptance criteria not met.
- BLOCKED: required environment, access, or prerequisite unavailable.
- NOT RUN: not attempted.
- NOT APPLICABLE: not relevant to the changed behavior, with a reason.

## Evidence record

For each meaningful run, record the date, environment/tool versions, exact command or test identifier, exit status, relevant output, and any differences from the intended target environment.
