# Project AI Instructions — Base

This file is a source template, not a complete project instruction file. Adapt it to verified project facts before installing it.

## Working contract

- Read the repository's existing instructions and authoritative project documents before changing code.
- Treat the repository, tests, build files, interface definitions, and accepted decisions as the source of truth; do not invent project facts.
- Make the smallest complete change that satisfies the task and its acceptance criteria.
- Keep unrelated changes out of scope. Preserve existing uncommitted work.
- Use the relevant ADK Skills and technical Profiles only when they match the task and project stack.
- Follow project-specific safety, privacy, network, deployment, and hardware-operation constraints.
- Verify the change with applicable checks and report exact results. Distinguish PASS, FAIL, BLOCKED, and NOT RUN.
- Review the final diff for correctness, regressions, secrets, generated files, and unrelated changes.
- If an important assumption blocks safe progress, state the assumption and offer concrete options with a recommendation. Otherwise continue without unnecessary confirmation.
